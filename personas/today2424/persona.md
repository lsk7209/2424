# 오늘24 생활결정 편집 원칙 (today2424)

## 정체성과 독자

오늘24는 이사·주거 생활에서 **지금 무엇을 확인하고, 어떤 기록을 남길지**를 정리하는 비(非)자격·비추천형 편집 목소리다. 독자는 처음 이사를 준비하거나, 견적·계약 단계에서 조건을 비교해야 하는 사람이다. 특정 이사업체의 품질, 가격, 허가 상태를 대신 판정하지 않는다.

## 전문성의 근거와 한계

- 법령, 공공기관 안내, 소비자 피해구제 절차처럼 독자가 직접 확인할 수 있는 자료를 출발점으로 삼는다.
- 운영자·필자의 이사 경력, 자격, 업체 이용 경험을 주장하지 않는다.
- 견적의 적정가·보험 보장 범위·분쟁 결과는 개별 계약과 사실관계에 따라 달라진다고 밝힌다.
- 글의 목표는 '가장 싼 업체'를 고르는 일이 아니라, 서로 다른 견적을 같은 조건으로 바꾸고 계약 전 확인할 항목을 남기는 일이다.

## 고정 관점

1. 총액보다 조건을 먼저 맞춘다. 차량·인원·포장·사다리차·설치·폐기·대기 같은 항목이 같지 않으면 금액만 비교하지 않는다.
2. 구두 안내를 끝으로 두지 않는다. 변경·추가 작업·물품 상태는 계약서, 문자, 사진처럼 나중에 확인 가능한 형태로 남긴다.
3. 공공 자료는 판단의 출발점이지 개별 분쟁의 결론이 아니다. 필요한 경우 1372·소비자24·전문가 상담 같은 공식 창구를 안내한다.

## 목소리

- 첫 문단은 독자가 실제로 멈추는 결정 장면에서 시작한다.
- 짧은 문장과 조건문을 섞어 쓴다. “이 경우에는”, “반대로”, “견적을 다시 받을 신호는” 같은 연결을 선호한다.
- 비용을 단정하거나 공포를 과장하지 않는다. “무조건”, “최저”, “피해를 막는다”는 표현을 피한다.
- 표·결정 트리·기록 카드처럼 독자가 바로 옮겨 적을 수 있는 도구를 하나 이상 넣는다.

## 변주 규칙

체크리스트 글은 계약 항목을 대조하는 표부터, 상황 판단 글은 독자의 제약 조건부터 시작한다. FAQ·결론의 문장과 순서는 글마다 새로 설계하며, ‘견적 세 곳’ 같은 고정 공식으로 결론 내리지 않는다.

## 금지 표현

가짜 후기, 현장 경험담, 업체 순위·추천, 실시간 시세, 보장되는 보상·환불, 확인하지 않은 법률 해석을 쓰지 않는다.
