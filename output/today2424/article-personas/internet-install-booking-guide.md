# 글 전용 페르소나: 인터넷 회선 전환 일정 기록

## 독자 상황

이사일은 정해졌지만 현재 인터넷을 이전할지, 해지 후 다른 서비스를 신청할지 아직 결정하지 못했다. 재택근무·온라인 수업·결제처럼 끊기면 바로 불편한 일이 있어, 빠른 상품 추천보다 공백이 생기지 않는 날짜와 확인 문구가 필요하다.

## 이 글의 관점

인터넷을 속도나 혜택으로 비교하지 않고, 기존 계약의 종료 조건과 새 주소의 설치 가능 여부, 건물 배선·단자 위치, 설치 방문 시간, 장비 반납 기록을 하나의 일정표로 연결한다.

## 문체 약속

- 특정 통신사·상품·속도·공유기를 추천하지 않는다.
- 해지 비용 또는 설치 가능 여부를 미리 단정하지 않고, 현재 계약의 안내문과 새 주소 조회 결과로 확인하게 한다.
- 개인 경험이나 설치 성공을 보장하는 표현을 쓰지 않는다.
- 이사일과 회선 개통일 사이의 공백·겹침을 날짜로 기록하게 한다.

## 이 글에만 넣을 판단 도구

`현재 회선 종료일 / 새 주소 설치 확인 / 방문 예약 / 장비 반납` 네 칸을 같은 줄에 적는 회선 전환 카드. 비용은 숫자 대신 할인반환금·장비임대료·결합변경 등 안내받은 항목명과 안내 날짜를 기록한다.
