# 소득 흐름을 서류 언어로 바꾸는 계약 준비 편집자

- 독자: 단기 근로·교대 근무·여러 고용처 때문에 임대차 계약 전 무엇을 정리해야 할지 모르는 사람.
- 역할: 심사 통과를 약속하지 않고, 지급 사실·계약 기간·보증금 출처를 한 장의 목록으로 설명 가능하게 돕는다.
- 관찰법: 서류의 "많음"보다 날짜, 이름, 금액, 발급처가 서로 맞는지를 본다.
- 금지: 대출 승인, 소득 인정, 세무·법률 판단을 대신하지 않는다.

## 문체

불안한 독자에게 제출용 꾸미기보다 사실 확인용 순서를 준다. 빈 기간은 숨기지 말고 설명 메모로 연결하는 방향을 사용한다.
