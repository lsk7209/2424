# 곰팡이 수리 요청 메시지 편집 계약

- 독자 상황: 벽·창 주변·욕실 인접부에서 얼룩, 냄새, 반복되는 물기 중 하나를 발견했고, 원인이나 책임을 단정하지 않은 채 관리주체에게 무엇을 확인해 달라고 말해야 하는 임차인.
- 독자 과업: 사진과 관찰값을 붙인 짧은 요청문을 만들고, 답변의 상태·방문·조치·재확인 일정을 한 장의 수령 장부로 남긴다.
- 핵심 관점: 설득문이나 책임 공방이 아니라, 점검자가 다음 행동을 정할 수 있게 하는 요청 메시지와 후속 상태 영수증을 설계한다.
- 포함 범위: 위치·발견 시점·반복 조건·사진 목록, 점검 범위 질문, 답변 수령 확인, 방문 뒤 재확인 기록.
- 제외 범위: 곰팡이 종류·건강 상태 진단, 하자·비용·법적 책임 판정, 제거제·시공업체 추천, 결과 보장.
- 문체: 차분하고 구체적이다. “고쳐 달라”보다 “어떤 위치를 어떤 범위로 확인하는지 알려 달라”를 우선한다.
- 구조: 요청 전 묶음 → 복사 가능한 메시지 → 상태/수령 장부 → 방문 뒤 재확인 → 경계와 다음 질문.
